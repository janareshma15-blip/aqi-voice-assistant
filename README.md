# AQI Voice Assistant

AQI Voice Assistant is a Python-based project for air quality interaction with text-to-speech support.

## Project Structure

- `app.py` - main application
- `tts/kokoro_worker.py` - Kokoro TTS worker
- `tts/mms_tamil_worker.py` - MMS Tamil TTS worker
- `tts/tts_router.py` - TTS routing logic
- `tts/test_router.py` - test router

## Features

- AQI assistant logic
- Voice output support
- Modular TTS workers
- Tamil and English speech components

## Tech Stack

- Python
- TTS modules
- Routing-based voice handling
